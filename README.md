# GUIorder: Graphical User Interface for gorder

Companion tool for [`gorder`](https://github.com/VachaLab/gorder), providing a simple GUI for specifying analysis parameters and managing configuration YAML files.

**⚠️ Under development. Not yet available!⚠️**

## Installation

1. [Install Rust](https://www.rust-lang.org/tools/install)

2. Install GUIorder:
```bash
$ cargo install guiorder
```

## Usage

For information about how to use this tool, refer to the [`gorder` manual](https://vachalab.github.io/gorder-manual/), specifically to the section dedicated to the [graphical user interface](https://vachalab.github.io/gorder-manual/guiorder.html).
